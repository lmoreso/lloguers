## Pantalla dels últims contractes
Aquesta pantalla mostra l'últim contracte de cada immoble, segons les condicions següents:
- Si un immoble encara no té cap contracte informat, també es mostra, però sense dades de contracte.
- Si un immoble no té cap contracte vigent avui, es mostra el contracte més recent.
- Si un immoble té un contracte vigent i un altre contracte amb data d'inici futura, apareix dues vegades: una fila per a cada contracte.

### Diferències amb la pantalla d'immobles
A la pantalla **Immobles** es mostra una sola fila per immoble, amb el contracte que té la data d'inici més recent, independentment de si està vigent o no.

### Què pots fer en aquesta pantalla?
- **Aplicar i treure filtres** per reduir el nombre de contractes que es mostren.
- **Editar un contracte** amb el botó del llapis de la primera columna.
- **Accedir a diverses accions** mitjançant el botó dels tres punts (`...`) de l'última columna:
  - Editar el contracte.
  - Revisar el lloguer.
  - Consultar els documents del contracte.
  - Afegir un contracte nou.
  - Editar l'immoble.
  - Eliminar el contracte.
- **Exportar els contractes visibles** a la pantalla, amb totes les dades dels contractes, dels inquilins i dels immobles. Pots triar el format d'exportació: CSV, OpenDocument o Excel.
